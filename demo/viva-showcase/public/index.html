External Examiner Walkthrough (8 Concrete Verification Steps)

Viva Examination Guide

This showcase was built specifically for an external examiner to evaluate authentication invariants directly using browser developer tools and real HTTP responses.

  1. Step 1: Log in through the Stateless JWT Baseline

    Select the Stateless JWT strategy pill. Click Alice Vance (Admin) and submit.

  2. Step 2: Inspect Application Storage

    Open Browser DevTools (F12) → Application → Local Storage. Notice the JWT access token stored under secureshop_jwt_token.

  3. Step 3: Inspect Network Request

    Open Network tab. Click Reload Orders via API. Observe the Authorization: Bearer <jwt> header sent to /api/jwt/dashboard.

  4. Step 4: Demonstrate Stateless JWT Replay Limitation

    Go to Security Experiments Lab → Comparison A. Capture the token, click Logout, and click Replay Token. Observe that the server returns HTTP 200 OK because the stateless server has no revocation state!

  5. Step 5: Demonstrate Ninsho Opaque Centralized Revocation

    In Comparison B, log in Alice under Opaque mode. Verify that queries to both Instance A and Instance B return 200. Click Revoke via Inst A. Replay the token against both instances. Observe that both return HTTP 401 Unauthorized immediately.

  6. Step 6: Inspect Ninsho DPoP Client Protection

    Log in under Ninsho DPoP. Inspect Local Storage → verify the access token is absent (kept in memory only). Inspect IndexedDB → verify the non-extractable crypto key in secureshop-dpop-keys. In Network, inspect the DPoP proof header and Authorization: DPoP <token> header.

  7. Step 7: Demonstrate DPoP Attack Resistance

    In Comparison C, click Simulate Token Theft Replay (sends token without DPoP proof) → returns HTTP 401. Click Attack with Wrong Key → returns HTTP 401. Click Replay Captured Proof → returns HTTP 401 (single-use JTI replay rejected).

  8. Step 8: Open Second Tab & Cross-Tab Invalidation

    Click Open Second Tab. With both tabs authenticated, log out in Tab 1. Watch Tab 2 instantly clear its session and transition to logged-out state via sessionSync.
